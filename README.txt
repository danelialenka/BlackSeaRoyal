BLACK SEA ROYAL HOTEL WEBSITE

Files:
- index.html
- styles.css
- script.js
- assets/black-sea-royal-logo.png
- assets/hotel-exterior.png

How to use:
1. Open index.html in a web browser.
2. Replace the sample phone number, email and exact address.
3. Update room descriptions, facilities and prices to match the hotel.
4. In script.js, replace reservations@example.com in the booking form handler.
5. Upload the folder contents to GitHub Pages, GoDaddy hosting or another static host.

Languages:
- English
- Georgian
- Russian

Important:
Kobuleti is on Georgia's Black Sea coast, so the website uses "Black Sea" rather than "Red Sea".
